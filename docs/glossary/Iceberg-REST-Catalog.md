# Iceberg REST Catalog

[全体像](../全体像.md) › 用語集

Apache Iceberg のテーブルと名前空間のメタデータを、REST のエンドポイントで公開するカタログ。

## Knowledge Catalog との関係

[Lakehouse runtime catalog](Lakehouse-runtime-catalog.md) がリモートのエンドポイントに接続し、メタデータを同期する。
