# クエリテンプレート

[全体像](../全体像.md) › 用語集

検証済みでパラメータ化された SQL を、自然言語の質問に結びつけて保存するもの。\
英語では query template。

## 持つ項目

`intent`、`nlQuery`、`query`、`sourceType`、`sourceDialect`、`parameters`。

## 例

質問「先月の売上は」に、月をパラメータにした集計の SQL を結びつける。説明用の例。
