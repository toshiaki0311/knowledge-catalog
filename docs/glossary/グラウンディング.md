# グラウンディング

[全体像](../全体像.md) › 用語集

AI エージェントの回答を、カタログにある業務のコンテキストに基づかせること。\
公式ドキュメントに独立した定義はなく、使われ方からの説明。

## 効果

ハルシネーションが減り、生成される分析の精度が上がる。

## 必要なもの

意味の定義、検証済みのクエリパターン、運用ルールの 3 つ。
