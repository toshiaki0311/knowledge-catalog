# MCP

[全体像](../全体像.md) › 用語集

LLM や AI アプリ、エージェントが外部のデータソースに接続する方法を標準化するプロトコル。\
Model Context Protocol の略。

## サーバーの種類

ローカルの MCP サーバーは利用者のマシンで動き、標準入出力で通信する。\
リモートの MCP サーバーはサービス側で動き、HTTP のエンドポイントを提供する。
