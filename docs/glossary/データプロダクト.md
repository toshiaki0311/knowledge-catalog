# データプロダクト

[全体像](../全体像.md) › 用語集

見つけやすく、信頼でき、利用できるように正式にパッケージ化された、データ資産の論理的なまとまり。

## 含められる資産

BigQuery のデータセット、テーブル、ビュー、ルーティン、モデル、外部テーブル。Cloud Storage のバケット、Iceberg REST Catalog、Looker の資産。

## Context Set との違い

データプロダクトはデータそのものを管理し、[Context Sets](../architecture/Context-Sets.md) は会話用の意味をまとめる。
