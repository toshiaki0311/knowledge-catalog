# Network attachment

[全体像](../全体像.md) › 用語集

プライベート IP しか持たない外部のデータベースへ、BigQuery Data Transfer Service が Private Service Connect で接続するために用意するもの。

## 要らない場合

公開 IP で接続するときは不要。
