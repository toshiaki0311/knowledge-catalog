# Change request

[全体像](../全体像.md) › 用語集

エンリッチメントエージェントが提案した変更を、承認されるまで保留しておく単位。\
データスチュワードが内容をレビューする。

## 扱い

250 件を超える提案は複数に分割され、順に承認する。\
削除の提案は別の change request になり、必ず人がレビューする。
