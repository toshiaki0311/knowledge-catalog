# Definition

[全体像](../全体像.md) › 用語集

技術的なデータ資産や列を、対応するビジネス用語集の定義に結ぶ Context Graph のエッジ。

## 例

`email_address` 列と、用語「顧客メールアドレス」の定義を結ぶ。説明用の例。
