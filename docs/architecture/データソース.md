# データソース

[全体像](../全体像.md) › ① データソース層

Knowledge Catalog は、Google Cloud のサービスからメタデータを自動で取り込む。\
たとえば BigQuery にテーブルを作ると、操作をしなくてもそのテーブルがカタログに登録される。

## 自動で取り込まれる Google Cloud のソース

| ソース | 取り込まれるもの |
|---|---|
| BigQuery | データセット、テーブル、ビュー、モデル、ルーティン、接続、リンクされたデータセット、グラフ（Preview） |
| BigQuery sharing | エクスチェンジ、リスティング |
| Cloud Storage | 自動検出されたデータ |
| Vertex AI | モデル、データセット、feature group など |
| Looker | ダッシュボード、Look、LookML、Explore、ビューなど |
| データベース | Bigtable、Spanner、AlloyDB for PostgreSQL（Preview）、Cloud SQL |
| その他 | Dataform、Dataproc Metastore、[Iceberg REST Catalog](../glossary/Iceberg-REST-Catalog.md)、Pub/Sub、Datastream |

AlloyDB と Cloud SQL は、連携を有効化してから取り込まれる。\
対象はプライマリインスタンスだけ。

## 自動で取り込まれないソース

Google Cloud の外にあるデータソースは、コネクタや自前のインポートで取り込む。\
方法は [分離された外部データソースからのメタデータ取り込み](../questions/分離された外部データソースからのメタデータ取り込み.md) にある。
