# 付加情報・管理機能

[全体像](../全体像.md) › ② Knowledge Catalog 層

メタデータに業務上の意味と[信頼シグナル](../glossary/信頼シグナル.md)を足す機能。

| 機能 | 内容 | 例 | 公式ドキュメント |
|---|---|---|---|
| Business glossary | 用語集、カテゴリ、用語で業務用語の分類体系を作り、用語を [Entry Link](メタデータモデル.md) で Entry や列に対応づける | 用語「売上」を定義し、売上金額の列に結ぶ | [用語集の管理](https://docs.cloud.google.com/knowledge-catalog/docs/manage-glossaries) |
| Data lineage | パイプラインをまたいで、列レベルの変換を追跡する | 集計テーブルの列が、どのテーブルのどの列から作られたかをたどる | [リネージ](https://docs.cloud.google.com/knowledge-catalog/docs/use-lineage) |
| Data profiling | スキャンで統計分布を計算し、スキーマの異常や統計的なドリフトを検出する | 列ごとの distinct count、null の割合、サンプル値 | [データプロファイリング](https://docs.cloud.google.com/knowledge-catalog/docs/data-profiling-overview) |
| Auto data quality | ルールベースの品質チェックを実行し、スコアを Entry に付ける | 「`email_address` が null でない」というルール | [自動データ品質](https://docs.cloud.google.com/knowledge-catalog/docs/auto-data-quality-overview) |
| Data insights | Gemini in BigQuery がクエリ履歴などからメタデータを生成する | 列の説明、テーブル間の結合キー、クエリ例 | [データインサイト](https://docs.cloud.google.com/knowledge-catalog/docs/data-insights-structured-data) |
